# メルフォト

撮った写真をメルカリ出品用に自動加工する iPhone 向けWebアプリ（PWA）。

- 正方形 1080×1080 の JPEG（「正方形に切り抜く」／「白い余白で全体」）
- 明るさ・色の自動補正（おまかせ／強め／補正なし）＋軽いシャープ
- 「写真を保存」→ iPhone の共有シートで「画像を保存」（または共有先にメルカリが出ればそのまま渡せる）
- 写真は端末の中だけで処理し、外部に送信しない（fetch・アップロードなし）
- 背景の差し替え（そのまま／真っ白／大理石／レンガ／木目／グレー）：商品をAIで切り抜いて中央に配置し、やわらかい影をつける。切り抜きは端末内で動くモデル（初回だけ約40MBを読み込み）。写真は送信しない
- 最大20枚（メルカリの上限）

背景の切り抜きに [@imgly/background-removal](https://github.com/imgly/background-removal-js)（AGPL-3.0）を使用。このアプリのソースもこのリポジトリで公開している。
